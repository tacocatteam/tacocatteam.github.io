# Team Tacocat rain garden project

This GitHub Pages site presents Team Tacocat's 2026–27 BIOGLOW Innovation Project: a proposed school rain garden. The public story is based on the team's engineering notebook. The full garden, final location, and experiment results are not represented as completed work.

`index.html` is the main site; `classroom.html` contains student lessons and quizzes. `question-bank.js` provides 500 question wordings over 50 rain garden and science concepts. TacoChat's browser fallback is in `tacochat.js`; its Cloudflare Worker is in `cloudflare-worker.js` and must be deployed separately from GitHub Pages.
